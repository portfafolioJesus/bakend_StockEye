# StockEye · Entrega final Fase 2

Documentación del proyecto ordenada según la estructura de entrega de Duoc (APT, Fase 2).

| Carpeta | Contenido |
|---|---|
| `Evidencias proyecto/Evidencias de documentación/Listado de CU y RF-RNF` | 25 RF, 15 RNF, trazabilidad con la Fase 1 y listado de 23 casos de uso |
| `…/Diagramas de CU` | Diagrama nivel 0 y diagramas por actor |
| `…/Planillas de CU` | Especificación de los 23 casos de uso |
| `…/Diagramas de actividad` | 6 flujos principales del sistema |
| `…/Documentación SCRUM` | Análisis del caso, épicas, sprints, historias de usuario y priorización |
| `Evidencias de sistema/Base de datos` | Diccionario de datos, modelo lógico, modelo relacional, NoSQL y script para poblar tablas |
| `Evidencias de sistema/Aplicación` | Ambiente de desarrollo (PDF) y repositorios documentados |
| `Evidencias de sistema/RESUMEN Estado de Avance CU.xlsx` | Avance por caso de uso |
| `ANEXOS` | a. Instructivo de instalación · b. Manual de usuario · c. Plan de pruebas · d. Carta Gantt |

Las carpetas `_fuentes/` tienen los scripts que generan los documentos y diagramas a partir de los datos
(requisitos, casos de uso, backlog y esquema de la base), para poder regenerarlos si algo cambia.
